# vercel-test

A minimal, self-contained **Next.js** app using the Vercel **Workflow SDK** and
**@workflow/ai**. It runs a durable chat agent that answers database-related
requests, and gates a consequential ("drop all tables") action behind an
approval webhook.

## Stack

- Next.js (App Router)
- `workflow` / `workflow/next` (`withWorkflow`) — durable workflow runtime
- `@workflow/ai` — agent streaming

## Run / deploy

```bash
npm install
npm run dev        # local
npm run build && npm start
```

Deploy to Vercel by importing this repo (Hobby plan is sufficient).

## Endpoints

- `POST /api/chat` — start a chat turn; the workflow's response streams back.
- `/.well-known/workflow/v1/...` — workflow runtime routes (generated by
  `withWorkflow`).

## Layout

- `workflows/chatFlow.ts` — the durable workflow (approval-gated action).
- `app/api/chat/route.ts` — the chat route.
- `app/page.tsx` — minimal UI.

This repository is a demo/experimental project.
